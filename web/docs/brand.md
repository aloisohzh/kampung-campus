# Kampung Campus visual identity

The website logo and PNG favicon use the exact artwork supplied by the project owner as **Kampong Campus Hackathon.png**. The source image is preserved unchanged at `public/brand/kampung-campus.png`; `public/favicon.png` contains the same image. CSS controls its display size and blends the white image background into the site's light surfaces. Visible wordmarks consistently read **Kampung Campus**.

The supplied [pitch deck](https://canva.link/dun6ml9aqzhe1c1), titled **Kampong Campus Hackathon**, provided the visual reference: cream paper backgrounds, deep forest green, bold rounded sans-serif headings, restrained terracotta accents, and neighbour-focused illustrations. The website adapts that direction with Nunito Sans headings and retains Geist for working controls and body text. The deck itself is unchanged.

Website palette: cream `#fff4df`, forest `#20543b`, terracotta `#ad542e`, paper `#fffdf8`. These are website adaptations of the observed deck, not a claimed extraction of a formal Canva brand kit. Status colours and provider-specific branding remain distinct.
