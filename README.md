# Kampung Campus

Pek Kio’s resident-led community platform.

- [OpenSpec proposal](openspec/changes/kampung-campus-platform/proposal.md)
- [Working private pilot app and setup](web/README.md)
- [Generated imagery and prompts](web/docs/generated-assets.md)

The implementation lives in `web/`. This first deliverable is a private, saved demonstration of the contribution-to-voucher journey, with separate resident, organizer, reviewer, operator and merchant views. It uses D1 and R2 through Sites. Partner pathways and credits are explicitly simulated.
